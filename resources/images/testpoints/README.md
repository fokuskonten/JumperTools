# KATALOG GAMBAR DIAGRAM TEST POINT & PINOUT MOTHERBOARD

Direktori ini digunakan untuk menyimpan foto diagram motherboard / titik pinout Test Point smartphone.

---

## 📸 FORMAT PENAMAAN GAMBAR

File gambar (format `.jpg` atau `.png`) dinamai berdasarkan kombinasi merek dan nama model/codename:

```
resources/images/testpoints/
├── xiaomi_redmi_note_8_tp.jpg
├── xiaomi_redmi_note_7_tp.jpg
├── xiaomi_poco_x3_pro_tp.jpg
├── xiaomi_redmi_9_tp.jpg
├── xiaomi_redmi_9a_tp.jpg
├── oppo_a5s_tp.jpg
├── oppo_a12_tp.jpg
├── oppo_a53_tp.jpg
├── vivo_y12_tp.jpg
├── vivo_y20_tp.jpg
├── samsung_a02s_tp.jpg
└── realme_c11_tp.jpg
```

Panduan teks instruksi lengkap untuk seluruh model di atas sudah tertanam langsung di dalam `TestPointRepository.cs` dan otomatis tampil di layar antarmuka **Test Point Library**.
